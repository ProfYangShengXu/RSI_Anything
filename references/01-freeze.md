# 01 冻结（G1）

## 预注册四项：少一项后面全是白跑

```
H0        起点：改之前的版本 + 它的读数（要能复现）
预算      硬上限（max_calls / max_wall_s / max_usd）+ 记账口径（in/out token、缓存、外部 API）
判据      谁算成功；必须能被机器判；分母写清楚（全部题 / 有产物的题）
样本量    先按要分辨的差距算需要多少题，再决定跑多少
聚合口径  失败算 0 / 剔除 / 单列；GT 质量差的题预先剔除还是保留
```

## 判据三档自证（五分钟，省一天）

```
原版产物   → 应得中等分（有对有错）
参考解     → 必须满分
垃圾答案   → 必须 0 分
```

三档不对，判据本身有问题。**判据没自证，一律不许跑模型。**

## 题面体检三检

```
① 能骗过吗   造一个“字面全对、实质全错”的假答案，判据必须红
② 稳吗       同一份产物判 3 次，结论必须一致
③ 唯一吗     标准答案是否唯一？描述够不够解题？
```

外加一条：**做体检的人不能是写判据的人**。

## 冻结 hash


## 预算的两个常见坑

```
① 上限只写在命令行，执行体自己不看 → 跑到天荒地老
② 一臂提前结束、一臂跑满 → 你比的是“多试几次”，不是方法
```
