# 01 冻结（G1）

## 预注册五项：少一项后面全是白跑

```
① H0        起点：改之前的版本 + 读数（要能复现）
② 预算      硬上限（max_calls / max_wall_s / max_usd）+ 记账口径
③ 判据      谁算成功；必须能被机器判；分母写清楚
④ 样本量    先算需要多少题，再决定跑多少
⑤ 聚合口径  失败算 0 / 剔除 / 单列；GT 差的题预先剔除还是保留
```

（`templates/prereg.md` 里的题面体检、单变量、迁移三节是附加记录，不计入“五项”。）

## 样本量怎么算（不要只写“先算”）

两臂配对、结果为对/错时，用 McNemar：

```
n ≈ ( z_(1-α/2)·√π + z_(power)·√(π − d²) )² / d²
π = 不一致率（两臂结论不同的比例），d = 要分辨的差异
```

按 π=0.15、α=0.05、power=0.8 算出来的现成数：

```
要分辨 15pp → 约 53 题/臂
要分辨 10pp → 约 118 题/臂
要分辨  8pp → 约 184 题/臂
要分辨  5pp → 约 471 题/臂
```

**先看自己有几道题，再决定能声称什么。** 15 题/臂只能分辨 15pp 以上。

## 判据体检（四件套）

### A 标定

```
s_orig  原版产物      s_ref  参考解      s_junk  垃圾（空文件/随机文本）
硬条件  s_ref = max；s_junk ≤ 0.1·s_ref；s_ref − s_orig ≥ 0.1
```

最后一条不达，说明这道题本身没区分度（原版快满分），换题，不要加判据。

### B 对抗集（≥ 5 类，逐类报分）

```
① 空产出  ② 抄题面  ③ 只满足关键词  ④ 结构对内容错  ⑤ 超集蒙对
硬条件  s_ref − s_fake_max ≥ 0.5 × (s_ref − s_orig)
```

意思：**判据识别假答案的力度，至少得达到它识别真改进力度的一半。**
拿 `templates/fake-answers.md` 逐类造，不许先看判据源码。

### C 敏感度

拿一个已知有效的改动（哪怕手工造），判据必须至少动 `0.5 × (s_ref − s_orig)`。
不动 → 判据能判真假、判不出好坏，G4 拿它测收益会全是零。

### D 鲁棒性

```
同产物判 3 次，分差 ≤ 0.02；换题序/换批量，分差 ≤ 0.02；judge hash 冻结
```

### 不过怎么办

```
假答案超上限 → 判据不合格，停，先修判据
区分度 < 0.1 → 题目没区分度，换题
敏感度不达 → 补一个能反映改进的面
```

★ 判据只读一个面（例如只看测试通过）会招来作弊；只读一个面时必须在 prereg 里声明，并补一个独立面交叉。

## 题面体检三检

```
① 唯一吗   标准答案是否唯一？描述够不够解题？
② 可达吗   题目要的东西在环境里真的存在吗（文件/帧/字段/接口）
③ 谁体检   做体检的人不能是写判据的人
```

第三条怎么落地：另起一个会话或子 agent 跑体检，判据脚本与题集交给它，
输出写 `verify/preflight-audit.md`，并在 STATE 的「关键决定」里记下是谁审的。

## 冻结 hash

```bash
python scripts/freeze_hashes.py $RUN --code <repo> --judge <judge.py> --data <tasks/>
python scripts/freeze_hashes.py $RUN --verify     # 跑后重算，有差异 exit 1
```

**不要用“再冻结一次”来比对** —— 那只会覆盖旧值。

## 预算的两个坑

```
① 上限只写在命令行，执行体自己不看 → 跑到天荒地老
② 一臂提前结束、一臂跑满 → 你比的是“多试几次”，不是方法
```
