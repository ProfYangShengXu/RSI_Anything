# 04 执行与验证（G4）

## 三条同

```
同起点    每题回 H0；更强的形式：本题先跑一次参考执行（reference）
同预算    调用次数/墙钟/金额一致；一臂提前结束要截齐
同评测壳  判据/题集/GT/计数器 hash 未变；变了作废
```

## 结论强度按样本量

```
n < 50/臂    只报个案方向，禁 p 值、禁“显著”
n ≥ 100      配对精确检验（McNemar exact）
n ≥ 几百      才谈误差棒与置信区间
```

**先算样本量再决定跑多少题。** 同一批题跑十遍还是 15 个样本。

## 报告必带四项

```
reward
总成本
成本分母（每题 / 每次成功）→ cost per solved task
失败签名（不是“失败了”，是“因为什么失败”）
```

## 迁移三轴（至少验两个）

```
换题     任务级留出，留一批不碰
换模型   同改法换 backbone
换工具面 同任务换接口
```

阈值先写死再跑：

```
留出收益 ≥ 一半  部分迁移；≥ 八成  成立
换模型后归零     model-specific
换工具面仍成立   才可标 invariant
```
